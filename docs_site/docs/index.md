# SSG Tether Capture documentation

**SSG Tether Capture** simulates the capture of orbital debris with a space tether. You choose a target and a chaser from the Space-Track catalog (or give their orbital elements), write a capture plan of phases with their limits and transitions, and watch, record and replay the capture in a desktop app, or run the same simulation headless with `ssg-sim`. Runs are deterministic: the same build, platform, project and inputs give bit-identical results.
